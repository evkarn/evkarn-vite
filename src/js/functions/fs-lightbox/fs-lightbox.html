Every element (anchor element) with the "data-fslightbox" attribute opens the lightbox. The content behind the URL or path passed to the "href" attribute will be displayed in the lightbox. Каждый элемент (якорный элемент) с атрибутом «data-fslightbox» открывает лайтбокс. Содержимое за URL-адресом или путем, переданным в атрибут «href», будет отображаться в лайтбоксе. There is no need to place anything specific inside of an element. Нет необходимости размещать что-либо конкретное внутри элемента . 0
